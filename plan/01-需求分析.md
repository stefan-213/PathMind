# 需求分析：AI 智能图表生成与对话系统

## 一、项目背景

当前 PathMind 系统已有基于 D3.js 的知识图谱展示功能，用户可以查看技术节点之间的关系。但缺乏智能图表生成能力，用户无法通过自然语言让 AI 自动生成各种可视化内容。

## 二、核心功能需求

### 2.1 图表生成

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 自然语言输入 | 用户通过自然语言描述图表需求 | P0 |
| AI 意图分析 | AI 分析用户意图，决定是否需要生成图表 | P0 |
| 图表类型适配 | AI 自动选择合适的图表类型（路线图/流程图/框架图） | P0 |
| 数据渲染 | 将 AI 返回的图表数据渲染到网页中 | P0 |

### 2.2 实时对话

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 对话交互 | 右侧面板支持与 AI 实时对话 | P0 |
| 图表修改 | 用户可通过对话要求 AI 修改图表 | P1 |
| 对话历史 | 保存对话历史，支持回溯 | P1 |

### 2.3 图表渲染

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 多类型支持 | 支持渲染 AI 返回的任意图表类型 | P0 |
| 节点交互 | 支持点击、拖拽节点 | P1 |
| 缩放平移 | 支持 SVG 缩放和平移 | P0 |

## 三、核心原则

### 3.1 前端"哑终端"原则

```
关键理解：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AI 返回什么图表类型 → 由 AI 和后端决定
后端返回什么数据格式 → 由 AI Prompt 决定
前端职责 → 接收数据 → 渲染图表
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

前端不参与业务决策，只负责：
1. 接收统一的 GraphData 数据结构
2. 根据 layout 字段选择渲染策略
3. 无条件渲染 AI 返回的图表
```

### 3.2 统一数据模型

无论 AI 返回什么类型的图表，前端使用统一的数据结构：

```typescript
interface GraphData {
  type: string;           // 图表类型（AI 决定：roadmap/flowchart/framework/tree 等）
  title: string;          // 图表标题
  nodes: GraphNode[];      // 节点列表
  edges: GraphEdge[];      // 边列表
  layout: 'force' | 'tree' | 'timeline' | 'grid';  // 布局类型（AI 决定）
}
```

## 四、用户故事

### 4.1 生成图表

```
场景：用户想要一个技术路线图
------------------------------------------
用户输入： "帮我画一个 React 技术路线图"
    ↓
AI 分析： 用户需要路线图类型
    ↓
后端返回： {
  type: 'roadmap',
  layout: 'timeline',
  nodes: [...],
  edges: [...]
}
    ↓
前端渲染： 时间轴布局渲染路线图
```

### 4.2 修改图表

```
场景：用户想要修改已生成的图表
------------------------------------------
用户输入： "把 React 改成 Vue"
    ↓
AI 分析： 用户想修改图表
    ↓
后端返回： {
  type: 'roadmap',
  layout: 'timeline',
  nodes: [/* Vue 相关节点 */],
  edges: [...]
}
    ↓
前端渲染： 自动重新渲染更新后的图表
```

## 六、非功能需求

### 6.1 性能需求

| 指标 | 要求 |
|------|------|
| 图表渲染时间 | < 2 秒（50 节点以内） |
| AI 响应时间 | < 5 秒 |
| 页面加载时间 | < 3 秒 |

### 6.2 兼容性需求

- Chrome、Firefox、Safari、Edge 最新版本
- 响应式设计，支持 1280px 以上屏幕

### 6.3 可扩展性

- 支持未来新增图表类型
- 支持 AI 返回自定义渲染指令
